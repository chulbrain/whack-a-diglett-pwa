# Whack a Diglett PWA

This project is a simple whack-a-mole style game built with React, TypeScript and Vite. Digletts pop up on the screen and you score points by clicking them before they disappear.

## Running Locally

```bash
cd my-react-app
npm install
npm run dev
```

Make sure dependencies are installed before running any lint or build commands.
